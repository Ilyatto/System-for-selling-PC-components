# Информационная система для компании по продаже комплектующих для ПК

## Запуск программы
1. Откройте файл `main.py` в PyCharm или любом другом редакторе Python
2. Запустите программу

## Подключение к базе данных
Перед запуском убедитесь, что:
- Установлен PostgreSQL
- Создана база данных `shop_db`
- В файле `main.py` в классе `Database` указаны ваши данные для подключения:

```python
self.conn_params = {
    'dbname': 'shop_db',
    'user': 'postgres',
    'password': '1234',
    'host': 'localhost',
    'port': '5432'
}
